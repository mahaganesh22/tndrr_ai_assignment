# Task 1: QLoRA fine-tuning for text-to-SQL

This folder contains the completed notebook and a modular Python implementation of the same experiment. The modular version fine-tunes `Qwen/Qwen2.5-0.5B-Instruct` on `b-mc2/sql-create-context` using 4-bit NF4 quantization and LoRA.

The run downloads the dataset and base model, trains the adapter, evaluates base and fine-tuned models on the same 100 held-out rows, prints up to three errors, and prints the 7B memory estimate. Outputs are written under `outputs/`, which is ignored by Git because model artifacts are large.

## Experiment settings

- Split: 5,000 training, 500 validation, 100 held-out test examples; seed 42.
- LoRA: rank 16, alpha 32, dropout 0.05; target modules `q_proj`, `k_proj`, `v_proj`, `o_proj`.
- Optimizer/training: learning rate `2e-4`, 3 epochs, batch size 4, gradient accumulation 4, 8-bit paged AdamW.
- QLoRA: NF4 4-bit base with double quantization. Trainer AMP is disabled for compatibility with Colab T4; adapters are kept in fp32.
- Metric: normalized SQL exact match (lowercase, whitespace normalized, one final semicolon ignored).
